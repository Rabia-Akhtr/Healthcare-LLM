# Healthcare AI RAG Assistant 🩺

A Retrieval-Augmented Generation (RAG) application that allows users to upload a medical PDF and ask questions using OpenAI and LangChain.

## Features
- Upload medical PDF
- Semantic search with FAISS
- Context-based answers
- Source chunk display
- Page citations

## Tech Stack
- Python
- Streamlit
- OpenAI API
- LangChain
- FAISS

## Run Locally

Install dependencies:
py -m pip install -r requirements.txt

Run the app:
py -m streamlit run app.py

## Use Case
This project demonstrates a production-style RAG pipeline for healthcare document question answering — suitable for LLM Engineer portfolios.
